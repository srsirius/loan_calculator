# Loan Calculator (CreditCalc)

Простой консольный калькулятор кредита на Python: поддерживает аннуитетные и дифференцированные платежи, считает переплату, срок или сумму кредита в зависимости от заданных параметров.

## Возможности

- **Аннуитетный платёж**: расчёт ежемесячного платежа, срока или суммы кредита — в зависимости от того, какой из трёх параметров не задан.
- **Дифференцированный платёж**: расчёт платежа по каждому месяцу и общей переплаты. Все входные параметры (`principal`, `periods`) должны быть заданы — `payment` не передаётся, а вычисляется.
- **Валидация входных данных**: проверка корректности типа кредита, процентной ставки, отсутствия отрицательных значений и количества неизвестных параметров.
- **Интерфейс командной строки**: все параметры задаются через аргументы CLI.

## Требования

- Python 3.8+
- Стандартная библиотека (дополнительные зависимости не требуются)

## Установка и запуск

```bash
git clone <URL-репозитория>
cd loan-calculator
python creditcalc.py
```

## Использование

Аргументы:

- `--type` — тип платежа: `annuity` или `diff` (обязательно).
- `--interest` — годовая процентная ставка в процентах (обязательно, > 0).
- `--principal` — сумма кредита.
- `--periods` — срок кредита в месяцах.
- `--payment` — ежемесячный платёж (используется только для аннуитета).

---

## Правила подстановки неизвестных параметров

### Для `--type annuity`
Должен быть ровно **один** неизвестный параметр из трёх: `principal`, `periods`, `payment`. Остальные два должны быть заданы.

### Для `--type diff`
- Все параметры должны быть заданы: `--principal` и `--periods` обязательны.
- Параметр `--payment` **не должен указываться**. Если он передан — будет ошибка.
- Неизвестных параметров нет — программа рассчитывает платёж по каждому месяцу и выводит переплату.

## Примеры использования

### Аннуитет: неизвестен платёж
```bash
python creditcalc.py --type annuity --interest 10 --principal 500000 --periods 60
```

### Аннуитет: неизвестна сумма кредита
```bash
python creditcalc.py --type annuity --interest 10 --payment 10000 --periods 60
```

### Аннуитет: неизвестен срок
```bash
python creditcalc.py --type annuity --interest 10 --principal 500000 --payment 10000
```

### Дифф: расчёт платежей по месяцам
```bash
python creditcalc.py --type diff --interest 10 --principal 500000 --periods 12
```

### Дифф: ошибка — указан payment
```bash
python creditcalc.py --type diff --interest 10 --principal 500000 --periods 12 --payment 50000
```
Вывод:
```text
Incorrect parameters
```

### Дифф: ошибка — не задан principal
```bash
python creditcalc.py --type diff --interest 10 --periods 12
```
Вывод:
```text
Incorrect parameters
```

### Дифф: ошибка — не задан periods
```bash
python creditcalc.py --type diff --interest 10 --principal 500000
```
Вывод:
```text
Incorrect parameters
```

## Ожидаемый вывод (пример для дифференцированного платежа)

При запуске:
```bash
python creditcalc.py --type diff --interest 10 --principal 500000 --periods 12
```
программа выведет:

```text
Month 1: payment is 45834
Month 2: payment is 45486
Month 3: payment is 45139
...
Month 12: payment is 41667

Overpayment = 27500
```
(конкретные значения зависят от округления вверх по формуле).

## Пример ошибки (некорректные параметры)

Если передать противоречивые данные, например нулевую ставку:
```bash
python creditcalc.py --type annuity --interest 0 --principal 500000 --periods 60
```
вывод будет:
```text
Incorrect parameters
```

Другие случаи ошибки:
- отрицательная величина любого из параметров;
- для аннуитета задано больше одного неизвестного параметра;
- для дифференцированного платежа указан параметр `--payment`;
- для дифференцированного платежа не задан `--principal` или `--periods`;
- неверный тип платежа (не `annuity` и не `diff`).

## Логика расчётов

- **Номинальная месячная ставка**: `i = interest / (100 * 12)`
- **Коэффициент аннуитета**:  
  `fraction = i * (1 + i)^n / ((1 + i)^n - 1)`
- **Аннуитетный платёж**: `A = P * fraction` (с округлением вверх до целого).
- **Срок при известном платеже**:  
  `n = ceil(log(A / (A - i * P)) / log(1 + i))`
- **Дифференцированный платёж за месяц m**:  
  `D_m = P / n + i * (P - P * (m - 1) / n)` (с округлением вверх).

## Ограничения и примечания

- Все денежные значения округляются вверх до целых рублей.
- Процентная ставка должна быть положительной.
- Отрицательные значения для `principal`, `periods`, `payment` считаются ошибкой.
- В режиме `diff` оба параметра `--principal` и `--periods` обязательны, `--payment` не указывается.
